Sign in

Calls POST /api/v1/auth/token. The access token is held only in this page's memory for the current session — never in localStorage, sessionStorage, a URL, or a log. Reloading the page signs you out.

Reads via GET /api/v1/accounts/{id}/balance and GET /api/v1/accounts/{id}/transactions. LedgerGuard has no account-list or account-detail endpoint, so an account id must be supplied.
